# 双层中英字体 V2

V2 不是把英文和中文挤进同一个字形，也不是一张静态效果图。它把每一对英文/中文行作为一个不可拆分的视觉单元：英文在上，中文在下。

## 当前实现

- `specimen/index.html`：可直接运行的双层排版编辑器。
  - 英文、中文分别逐行输入。
  - 实时预览逐行配对。
  - 独立调整英文字号、中文字号和两层间距。
  - 行数不一致时明确警告，缺失行留空，不会静默错配。
  - 可导出独立 HTML 文件。
- `DESIGN.md`：字形与排版设计规范。
- `TECHNICAL_PLAN.md`：字体文件与排版器的技术路线。

## 字体文件的关键限制

普通 TTF/OTF 不会理解英文语义，也不会自动生成中文译文。字体只能显示已经提供的字形。因此，“任意英文句子下面自动出现对应中文”必须由翻译/排版程序提供文本配对，不能靠字体 cmap 自己完成。

后续字体文件路线是为每一对已知文本生成一个文档专用组合字形，并用 PUA 私用区编码；排版器负责把文本对映射到这些字形。该字体适合嵌入对应文档，不等同于可以直接输入任意句子的通用系统字体。
