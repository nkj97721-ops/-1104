# 双层中英字体 V2

这是一个真正面向字体文件与排版验证的项目，不是单张效果图。

## V2 目标

- 英文在上，中文在下。
- 两层紧凑，视觉上作为一个整体。
- 英文与中文按行对应，而不是把中文塞进独立候选栏或旁注。
- 优先验证真实字体文件（OTF/TTF）与实际排版效果。

## 先说明一个关键技术边界

普通 TTF/OTF 的字体映射是“一个 Unicode 字符 → 一个字形”。它不会理解整句英文，也不会自动翻译或生成对应中文。因此，**任意英文段落与其中文译文逐行对应**，不能仅靠一个普通字体文件自动完成。

V2 将采用两层实现：
1. **字体层**：设计紧凑的英文字形与中文字形风格规范，并输出可安装字体资源。
2. **排版层**：将英文行与对应中文行作为一个双层行单元排版，控制行距、基线与对齐；不伪称字体本身能翻译文本。

## 项目状态

当前仓库从空仓库开始。首批提交建立设计规范、技术边界和可复现的验证方案。尚未生成或发布 OTF/TTF 成品。
